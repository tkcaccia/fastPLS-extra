# Benchmark data redistribution and acquisition

The fastPLS source repository does not redistribute prepared real-data benchmark
matrices. This policy is deliberately more conservative than the access status
of the upstream data: a public download does not, by itself, grant fastPLS the
right to repackage and redistribute a processed copy under the package licence.
Users should acquire each source from its authoritative provider, retain the
provider's terms, and create the prepared benchmark object locally.

## What is redistributed

| Object | Redistribution status | Reason |
|---|---|---|
| `breast` and `colon` package examples | Bundled with fastPLS | Derived from GPL-compatible R packages; provenance and citations are in `inst/DATA_SOURCES.md` and the help pages. |
| Synthetic benchmark generators and outputs | Redistributed | Generated by fastPLS scripts with fixed seeds and contain no source-study observations. |
| Aggregate benchmark CSV files, plots, run manifests, split indices, and checksums | Redistributed | These are generated analytical products and do not contain source matrices or participant-level records. |
| Prepared real-data matrices | Not redistributed | They must be reconstructed from the original sources under the applicable source terms. |

The prepared objects expected by the benchmark loader are listed by:

```sh
Rscript benchmark/acquire_publication_datasets.R --list
```

The loader can be pointed to an existing prepared object with
`FASTPLS_<DATASET>_RDATA`; for example:

```sh
FASTPLS_NMR_RDATA=/secure/data/nmr.RData \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=nmr --out="$HOME/fastPLS_sources"
```

The acquisition script writes `acquisition_manifest.csv`, including source
URLs, access class, local paths, file sizes, and MD5 checksums. It never
substitutes a newer release for an unavailable historical benchmark release.

## Public source acquisition

The following command downloads or resolves the public source files. It does
not alter an existing prepared benchmark object.

```sh
Rscript benchmark/acquire_publication_datasets.R \
  --dataset=cifar100,cbmc_citeseq,retina,metref,tabula,gtex_v8,tcga_brca,tcga_hnsc_methylation,tcga_pan_cancer \
  --out="$HOME/fastPLS_sources"
```

Dataset-specific sources are:

- **CIFAR-100:** official University of Toronto archive. The standard
  50,000/10,000 split is retained.
- **CBMC CITE-seq:** GEO accession GSE100866 RNA and ADT count files.
- **Retina:** GEO accession GSE63472. The publication benchmark additionally
  used the openTSNE `pca_50` representation; the acquisition workflow records
  both sources so that this preprocessing choice is explicit.
- **MetRef:** the `MetRef` object distributed by KODAMA. The benchmark removes
  zero-sum variables and applies the documented KODAMA normalization and
  scaling functions.
- **Tabula Muris:** Bioconductor ExperimentHub record EH1617
  (`TabulaMurisDroplet`), followed by the documented normalization, variable
  selection, and PCA50 preprocessing.
- **GTEx v8:** open-access GTEx gene-level expression and phenotype data from
  UCSC Xena. Protected sequence and donor-level files are not used.
- **TCGA-BRCA, TCGA-HNSC methylation, and TCGA Pan-Cancer:** open-access
  expression/methylation and phenotype matrices from UCSC Xena.

`UCSCXenaTools`, KODAMA, or Bioconductor data packages may be required for the
corresponding source. If a dependency is absent, the script stops that dataset
with an executable installation command instead of installing software without
the user's knowledge.

## Restricted, gated, or release-controlled sources

These datasets are not downloaded automatically. Obtain them from the provider,
accept any applicable terms, and then run the validation command.

### ImageNet/DINOv2

ImageNet access is account-gated and restricted to the uses in the ImageNet
terms. ImageNet does not own the copyright in the source images. Neither the
images nor the prepared DINOv2 embeddings are redistributed by fastPLS.

1. Request access at <https://www.image-net.org/download.php>.
2. Extract DINOv2 features from the authorized local image copy, preserving the
   checkpoint, pooling rule, row order, labels, and source split metadata.
3. Validate and checksum the prepared archive:

```sh
FASTPLS_IMAGENET_RDATA=/secure/data/imagenet.RData \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=imagenet --out="$HOME/fastPLS_sources"
```

The historical publication archive did not retain an authoritative canonical
train/validation flag. Its noncanonical 1,000,000/281,167 development split is
therefore reported as exploratory and must not be represented as the standard
ImageNet split.

### NMR

The source spectra are associated with the cited NMR study. The study reports a
Figshare data share and cohort metadata in MetaboLights accessions MTBLS242,
MTBLS395, and MTBLS424. Obtain the data under the source-study access and reuse
terms; fastPLS does not redistribute the prepared 13,000-by-28,355 task.

```sh
FASTPLS_NMR_RDATA=/secure/data/nmr.RData \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=nmr --out="$HOME/fastPLS_sources"
```

Source entry points:

- <https://figshare.com/s/2523b08fe8c2a23a341d>
- <https://www.ebi.ac.uk/metabolights/MTBLS242>
- <https://www.ebi.ac.uk/metabolights/MTBLS395>
- <https://www.ebi.ac.uk/metabolights/MTBLS424>

### CCLE

The publication benchmark used the historical DepMap/CCLE 18Q2 RNA-seq RPKM
matrix. Its former UCSC Xena endpoint is no longer a stable public download.
The workflow therefore requires the exact archived release and does not replace
it with a current DepMap release.

```sh
FASTPLS_CCLE_RDATA=/secure/data/ccle.RData \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=ccle --out="$HOME/fastPLS_sources"
```

If the prepared object is unavailable, supply the exact source files instead:

```sh
FASTPLS_CCLE_EXPRESSION=/secure/data/CCLE_DepMap_18Q2_RNAseq_RPKM_20180502 \
FASTPLS_CCLE_ANNOTATION=/secure/data/CCLE_sample_info_file_2012-10-18.txt \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=ccle --out="$HOME/fastPLS_sources"
```

### PRISM

PRISM source data are distributed through DepMap. The benchmark used a
release-specific molecular-profile/drug-response pairing, so the exact source
copy or prepared object must be supplied rather than silently using the latest
portal release.

```sh
FASTPLS_PRISM_RDATA=/secure/data/prism.RData \
  Rscript benchmark/acquire_publication_datasets.R \
  --dataset=prism --out="$HOME/fastPLS_sources"
```

Provider entry points:

- <https://depmap.org/repurposing/>
- <https://depmap.org/portal/data_page/?release=PRISM+Repurposing+19Q4&tab=allData>

## Prepared-object contract

The acquisition workflow records source files but does not guess the
study-specific filtering or split. Prepared objects should be named as reported
by `--list` and should contain the matrices and labels expected by
`benchmark/helpers_dataset_memory_compare.R`. Before a publication run:

1. preserve source and prepared-object checksums;
2. record all retained sample and feature identifiers;
3. estimate all preprocessing parameters from training data only;
4. preserve the fixed split indices and seed;
5. keep source data outside the Git repository; and
6. publish only aggregate outputs unless the source terms explicitly permit
   redistribution of the processed data.
