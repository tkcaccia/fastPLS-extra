# Archived workflow source

This directory preserves source code from earlier manuscript assembly cycles.
It is not part of the current benchmark manifest and must not be used to
generate evidence for a frozen package release.

The archived scripts are retained only to document how older documents were
assembled. They may contain obsolete release identifiers and result layouts.
Current benchmark runners are indexed by `benchmark/MANIFEST.csv`; current
figure and document builders are documented in `tools/README.md`.
